# 5분 액티브 포트폴리오 촬영 런북

## 고정 조건

- 촬영 URL: `http://127.0.0.1:8000/?demo=1`
- 영상: 1920×1080, 60fps, 최종 길이 300초
- 합성 데이터 접두사: `video_demo_20260804_`
- 마우스: 목표까지 0.4~0.8초 곡선 이동, 클릭 전 0.2~0.4초 대기
- 화면 변화: 2.5초 안에 커서 이동, 스크롤, 체크, 입력, 진행률, 토스트, 차트 또는 전환 중 하나를 발생시킨다.
- 자막: 앱 하단 프로세스 자막과 번인 SRT를 함께 사용한다. SRT는 앱 자막과 겹치지 않도록 상단 안전 영역에 배치한다.
- 외부 LLM은 호출하지 않는다. VOC Improved에는 `촬영용 합성 실행 · 외부 LLM 미호출 · LLM Judge: SKIPPED`를 표시한다.

## 촬영 전 상태

1. `docker compose up -d --build` 후 앱·Prometheus·Grafana가 모두 healthy인지 확인한다.
2. Chrome에는 앱과 AWS CloudFormation 두 탭만 남긴다.
3. 앱은 승인된 관리자 세션으로 열고, 회원 등록 장면용 별도 로그아웃 탭을 준비한다.
4. OBS 녹화 상태가 `false`, 캔버스가 1920×1080, 출력이 60fps인지 확인한다.
5. API 키, Jira, 웹훅, 이메일, 내부·공인 IP가 데모 마스크로 가려졌는지 확인한다.
6. 같은 접두사의 이전 합성 데이터를 정리한다.

## 촬영 실패 조건

- 체크박스의 파란 배경과 흰색 체크가 보이지 않거나 DOM 상태와 다르다.

- 자막의 기능·프로세스·결과가 실제 화면과 다르다.
- 3초 이상 화면 변화가 없거나 커서가 순간이동한다.
- Prometheus·Grafana 차트가 비어 있다.
- AWS 식별 정보 또는 앱의 키·이메일·IP가 보인다.

하나라도 발생하면 해당 원본 클립을 사용하지 않고 원인을 수정한 뒤 다시 촬영한다.
