# 한국어 포트폴리오 영상 내레이션 설계

## 목표

기존 5분 영상과 한국어 자막 75개를 유지하면서, 자막 내용을 차분한 한국어 여성 음성으로 읽는 AAC 내레이션 트랙을 추가한다. 무음 원본 `portfolio-demo-docker.mp4`는 보존하고 `portfolio-demo-docker-narrated.mp4`를 새 산출물로 만든다.

## 음성 및 동기화

- Windows에 설치된 `Microsoft Heami Desktop`(`ko-KR`, Female)을 사용한다.
- 외부 TTS API를 호출하지 않으므로 네트워크, API 키, 크레딧이 필요하지 않다.
- SRT의 `\\an8` 위치 태그를 제거한 실제 문장만 읽는다.
- 각 자막의 4초 슬롯마다 음성을 별도 생성한다.
- 음성이 슬롯보다 길면 FFmpeg `atempo`로 잘리지 않게 압축하고, 짧으면 뒤에 무음을 채운다.
- 각 슬롯을 정확히 4초로 만든 뒤 75개를 연결해 300초 내레이션을 생성한다.
- 최종 음량은 대화 중심 수준으로 정규화하고, 영상은 스트림 복사하며 음성만 AAC 48kHz로 인코딩한다.

## 오류 처리

- 설치 음성이 없거나 SRT 큐가 75개·300초를 완전히 덮지 않으면 생성하지 않는다.
- 개별 음성 생성이나 FFmpeg 변환이 실패하면 최종 파일을 교체하지 않는다.
- 임시 산출물과 최종 산출물을 분리하고, 검증된 파일만 최종 이름으로 이동한다.

## 검증

- 자막 파서와 4초 슬롯 계산을 자동 테스트한다.
- 최종 영상이 300초, 1920×1080, 60fps인지 확인한다.
- AAC 오디오 스트림이 존재하고 전체 디코딩이 성공하는지 확인한다.
- 대표 시작·중간·마지막 구간을 재생 또는 파형으로 확인해 음성 동기화를 점검한다.
- 기존 영상의 단계 카운터, 작업표시줄 제거, 자막, 정지 화면 기준은 그대로 유지한다.
