# OBS 촬영 오버레이 타임라인

촬영 URL은 `http://127.0.0.1:8000/?demo=1`이다. 데모 컨트롤러의 다음 버튼으로 12개 단계를 진행하며 파일 업로드와 실행 단계에서는 자동 재생이 멈춘다.

| 시간 | 단계 | 화면·대상 | 동작 | OBS 메모 |
|---|---:|---|---|---|
| 0:00~0:20 | 1 | 전체 `.tabs` | 메뉴를 천천히 훑는다 | 녹화 시작 후 2초 정지하고 시작 |
| 0:20~0:45 | 2 | `#connection-settings-card` | 공급자 목록만 열고 저장하지 않는다 | 키·Jira·IP 마스킹 확인 |
| 0:45~1:05 | 3 | `#file` | `qa_dataset.json` 선택 후 업로드 | 파일 선택 창에 개인 파일이 없어야 함 |
| 1:05~1:20 | 4 | `#file-testcase` | 실행 탭 이동 후 `qa_testcases.json` 업로드 | 업로드 완료 체크리스트 표시 |
| 1:20~2:05 | 5 | `#pipeline-run-card` | rag·llm_quality 확인 후 실행 | 20초 초과 시 이력 결과로 전환 |
| 2:05~2:45 | 6 | `#tab-dashboard` | 개요와 차트, 표로 보기 | 차트 한 개만 확대 |
| 2:45~3:15 | 7 | 실행 이력 영역 | 보고서 버튼과 이력을 표시 | 다운로드 트레이가 화면을 가리지 않게 함 |
| 3:15~3:50 | 8 | `#tab-voc-analysis` | 합성 VOC 업로드와 지시문 표시 | 외부 API 실행은 생략 가능 |
| 3:50~4:05 | 9 | `#tab-voc-results` | 사전 생성 합성 결과를 표시 | `SKIPPED`와 사전 생성 문구가 프레임에 보여야 함 |
| 4:05~4:30 | 10 | `#tab-monitoring` | 운영 지표와 Uptime 영역 표시 | 비어 있는 Uptime은 설명만 함 |
| 4:30~4:45 | 11 | `#k6-target-url` | `/health`, 1 VU, 10초와 Pass 이력 표시 | Prometheus/Grafana 오류 영역으로 스크롤 금지 |
| 4:45~4:58 | 12 | `.admin-nav-label` | 관리 메뉴를 훑고 대시보드로 복귀 | 4:58에 화면 정지 후 녹화 종료 |

## 클릭 및 자막 규칙

- 데모 모드의 분홍색 펄스 테두리가 현재 설명 대상을 표시한다.
- 모든 브라우저 클릭은 분홍색 원형 파동으로 표시된다.
- 하단 데모 자막과 SRT의 문구가 충돌하지 않도록 SRT는 음성 내레이션 용도로 사용한다.
- 실제 영상에 음성이 없으면 SRT를 영상 편집기에서 자막 트랙으로 불러온다.
- API 키, 웹훅, 이메일, Jira URL·토큰, 내부·공인 IP는 어떤 프레임에서도 읽혀서는 안 된다.
