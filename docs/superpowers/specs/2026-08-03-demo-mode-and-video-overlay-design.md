# 데모 모드 및 영상 오버레이 설계

## 목표

5분 포트폴리오 영상에서 사용자가 어떤 기능을 클릭하고 있는지 즉시 이해할 수 있도록 브라우저 자체 데모 안내와 영상 후처리용 자막을 함께 제공한다. 일반 사용 환경에는 영향을 주지 않으며 URL에 `demo=1`이 있을 때만 활성화한다.

## 사용자 경험

- `/?demo=1`로 접속하면 화면 우측 하단에 데모 컨트롤러가 나타난다.
- 각 단계는 대상 요소를 펄스 테두리로 강조하고 화면 하단에 기능 설명을 표시한다.
- 컨트롤러는 이전, 재생·일시정지, 다음, 종료 기능과 현재 단계/전체 단계 표시를 제공한다.
- 자동 재생 중 실제 파일 업로드, QA 실행, VOC 실행, 외부 페이지 이동이 필요한 단계에서는 자동 클릭하지 않고 일시정지해 사용자가 안전하게 수행하도록 한다.
- 사용자가 대상 버튼을 클릭하면 클릭 지점에 짧은 원형 애니메이션이 표시되고 다음 단계로 진행한다.
- 설정 화면의 비밀 입력값, Jira 이메일·토큰·URL, 상단 내부·공인 IP 표시에는 데모 모드 동안 불투명 마스킹을 적용한다.
- 데모 종료 또는 `demo=1`이 없는 일반 화면에서는 모든 안내·마스킹 요소가 제거된다.

## 단계 구성

1. 전체 메뉴와 시스템 목적
2. 연결 설정과 지원 공급자
3. 데이터셋 업로드
4. 테스트 케이스 업로드
5. QA 평가 기법과 실행
6. 대시보드 및 표 보기
7. 보고서와 실행 이력
8. VOC 파일 분석
9. VOC 사전 생성 대체 결과
10. 운영 모니터링
11. k6 성능시험
12. 사용자·오류·IP 관리와 마무리

각 단계는 `target`, `title`, `description`, `duration`, `pauseForAction` 필드를 가진 데이터 객체로 관리한다. 현재 화면에 대상이 없으면 해당 메뉴로 이동하라는 설명을 보여주고 자동 재생을 일시정지한다.

## 구현 구조

- `app/static/demo-mode.css`: 강조 테두리, 클릭 파동, 자막 패널, 컨트롤러, 마스킹 스타일
- `app/static/demo-mode.js`: 단계 상태, 대상 탐색, 자동 재생 타이머, 수동 제어, 클릭 효과, 화면 전환 대응
- `app/templates/index.html`: 데모 CSS·JS 로드
- `app/templates/monitoring_addon.html`: 동일 자산 로드해 페이지 이동 후에도 데모 안내 유지
- `demo/video/portfolio-demo.ko.srt`: 승인된 내레이션의 영상 편집용 한국어 자막
- `demo/video/overlay-timeline.md`: 단계별 화면, 대상 요소, 자막 시간과 OBS 촬영 메모

정적 자산은 항상 로드하되 스크립트가 `demo=1`을 확인한 뒤에만 DOM을 추가한다. 별도 서버 상태나 데이터베이스는 사용하지 않는다. 현재 단계는 `sessionStorage`에 저장해 모니터링 애드온으로 이동해도 이어간다.

## 오류 및 안전 처리

- 대상 요소가 없거나 숨겨져 있으면 예외를 발생시키지 않고 “해당 화면으로 이동해 주세요” 안내를 표시한다.
- 파일 선택, API 실행, 삭제, 설정 저장은 자동으로 수행하지 않는다.
- 마스킹 대상은 실제 값을 읽지 않고 CSS로만 덮는다.
- 데모 모드가 아닌 화면에서는 클릭 이벤트와 타이머를 등록하지 않는다.
- URL에서 `demo=1`을 제거하거나 종료 버튼을 누르면 즉시 일반 화면으로 복귀한다.
- VOC 대체 결과 자막에는 `사전 생성 합성 데모 결과`, 독립 Judge에는 `SKIPPED`를 명시한다.

## 검증 기준

- `demo=1`에서만 컨트롤러와 마스킹이 보인다.
- 이전·재생·일시정지·다음·종료가 정상 동작한다.
- 단계 변경 시 강조 대상과 자막이 함께 갱신된다.
- 클릭 파동이 표시되고 기능의 원래 클릭 동작을 방해하지 않는다.
- 설정 비밀값과 상단 IP가 1920×1080 스크린샷에서 읽히지 않는다.
- 메인 화면과 모니터링 애드온 사이에서 단계가 유지된다.
- SRT 타임코드가 오름차순이며 총 길이가 5분을 넘지 않는다.
- 기존 UI·API 회귀 테스트가 통과한다.
