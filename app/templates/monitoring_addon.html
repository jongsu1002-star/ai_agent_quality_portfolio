모니터링 애드온 - 성능테스트(k6) · Prometheus/Grafana

이 페이지는 기존 QA 품질관리·운영 모니터링 화면(메인 대시보드)과 완전히 별도로 동작합니다 - 여기서 무엇을 하든 기존 화면/API에는 영향을 주지 않습니다.

k6 성능테스트 실행

웹에서 바로 성능테스트를 실행합니다. 대상은 localhost 또는 사내망 IP(10.x/172.16-31.x/192.168.x)만 허용됩니다(외부 인터넷 주소는 거부) - 이 서버 자체나 사내 다른 서비스만 테스트할 수 있습니다. 동시사용자수는 최대 50명, 지속시간은 최대 2분까지입니다. 한 번에 하나만 실행할 수 있습니다.

경로는 대상 URL 뒤에 그대로 붙여서 요청합니다 (기본값 / - 이 플랫폼 자신을 테스트할 때는 더 가벼운 /health를 입력해도 됩니다. 다른 서비스면 그 서비스가 실제로 갖고 있는 경로를 입력하세요 - 없는 경로면 전부 실패로 집계됩니다).

체크하면 {"요청필드명": "발화문"} 형태로 POST 요청을 보내 실제 챗봇 API를 부하테스트합니다. 체크하지 않으면(기본값) 기존처럼 단순 GET으로 응답 상태만 확인합니다. 요청 필드명은 대상 챗봇이 기대하는 JSON 키에 맞게 바꾸세요(예: message, question).

Prometheus / Grafana

아래 스택은 infra/docker-compose.monitoring.yml로 별도 실행해야 보입니다 (기존 docker-compose.yml과 별개). 실행 방법은 사용자_매뉴얼.md 11장 (메인 대시보드 → 설정 탭 → 문서 카드에서 확인 가능) 참고.

Prometheus 쿼리 (실시간 차트)

qa_platform_total_requests (누적 총 요청수)의 최근 1시간 추이 - Prometheus 자체 UI를 iframe으로 그대로 넣는 대신, Prometheus HTTP API에서 직접 값을 받아와 이 페이지 스타일로 그립니다(제품 자체 React UI를 크로스오리진 iframe에 넣으면 자동 실행이 안 되는 경우가 있어 더 안정적인 방식으로 대체함).
