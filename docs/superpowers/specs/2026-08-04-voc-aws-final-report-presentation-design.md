# VOC Improve × AWS 확장 최종완료보고 PPT 디자인

## 목표

교육 평가자와 포트폴리오 검토자가 2팀의 실제 구현 범위, 품질 검증 결과, AWS 운영 경험과 한계를 빠르게 이해할 수 있는 16:9 PowerPoint 완성본을 만든다. 제공된 28페이지 PDF를 근거 자료로 사용하되, 빈칸과 작성 지시문을 제거하고 중복 슬라이드를 통합해 22장으로 정리한다.

## 사실 기준

- 전체 테스트: 650건
- 통과: 650건
- 실패: 0건
- 통과율: 100%
- 독립 LLM Judge: SKIPPED
- Judge 미실행은 PASS로 표시하지 않고 `UNVERIFIED`로 설명한다.
- 최종 판정: 합성 데이터 QA와 AWS 운영 경로는 검증 완료. 외부 LLM Judge 미실행 때문에 전면 운영 배포는 보류하고 조건부 스테이징 가능으로 판정한다.
- AWS 증빙: IAM/MFA, Zero Spend Budget, Free Tier 확인, S3 업로드, 퍼블릭 접근 차단, SSE-S3 암호화, SHA-256 무결성, CloudTrail 작업 감사, 객체·버킷 삭제 확인.
- 영상 산출물: 한국어 내레이션이 포함된 5분 24초 포트폴리오 영상.

모든 수치는 제공 PDF와 저장소의 `docs/테스트_결과.md`, `docs/사용자_매뉴얼.md`, `docs/프로세스_명세서.md`, AWS 운영 문서를 근거로 한다. 확인되지 않은 E2E 시간, Judge 점수, 비용 절감액은 만들지 않는다.

## 시각 체계

- 화면비: 16:9 와이드
- 배경: 밝은 회색 `#F5F7FA`
- 본문: 네이비 `#0F172A`
- 강조색: 파랑 `#2563EB`, 초록 `#16A34A`, 주황 `#F97316`
- 경고·보류: 주황, 실패: 빨강 `#DC2626`
- 글꼴: 맑은 고딕. 제목 36pt 이상, 중간 제목 24pt 이상, 본문 16pt 이상
- 기존 PDF의 좌측 색상 레일과 절제된 색상 체계를 계승하되, 반복 카드와 빈 캡처 상자를 줄인다.
- 한 슬라이드는 하나의 핵심 주장만 전달한다.
- 실제 화면 캡처는 원본 비율을 유지한다. 계정 ID, 이메일, IP, 버킷 식별정보와 기타 민감정보는 노출하지 않는다.
- 제목은 한 줄로 유지하고, 본문은 의미 단위로 줄바꿈한다.

## 콘텐츠 작성 규칙

- `수치 입력`, `캡처 삽입`, 밑줄, 빈 체크박스와 예시 문구는 최종 슬라이드에서 제거한다.
- `oCam`, `Cam`은 `포트폴리오 시연 영상`으로 통일한다.
- `Judge 결과 파일 생성`처럼 실제 상태와 충돌하는 문장은 삭제하고 `SKIPPED`로 교정한다.
- `완료`, `PASS`, `SKIPPED`, `조건부`는 각각 다른 의미로 사용한다.
- AWS 계정·리소스 고유 식별자는 화면에 남기지 않는다.
- 명령어는 전체 로그가 아니라 재현에 필요한 핵심 명령만 남기고 상세 절차는 발표자 노트 또는 부록 설명으로 축약한다.
- 페이지 번호는 1부터 22까지 연속으로 표시한다.
