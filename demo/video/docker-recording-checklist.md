## 촬영 후 증적

- 최종 파일: `demo/video/portfolio-demo-docker.mp4`
- OBS 원본: 촬영 후 기록
- 재생 시간: `300.000초` 확인 후 기록
- 해상도·프레임레이트: `1920×1080·60fps` 확인 후 기록
- 파일 크기: 촬영 후 기록
- 전체 디코딩: FFmpeg exit 0 확인 후 기록
- 최대 정지 구간: `3.000초 미만` 확인 후 기록
- SRT 범위: `00:00:00,000`~`00:05:00,000`, 3초 이상 공백 없음
- 체크박스 전후 프레임: 각 체크박스 유형별 캡처 기록
- 등록·수정·삭제 전후 프레임: 각 실제 쓰기 기능별 캡처 기록
- 프로세스 자막: 모든 기능 구간에서 기능·처리·결과 문구 확인
- 민감정보: 키·토큰·이메일·AWS 계정·내부·공인 IP 노출 없음
- 회귀 테스트: 전체 테스트 결과 기록
- SHA-256: 촬영 후 기록
- 외부 API 호출: 없음
